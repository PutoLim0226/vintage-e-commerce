顧客購物與行銷 API 模組 (Customer & Marketing Endpoints)

GET /api/products/filter-metadata

公開端點。動態計算全站有庫存之商品的顏色清單、尺寸清單，以及商品 base_price 的最高/最低值，用於前端複合篩選側邊欄。

GET /api/wishlist

會員專屬。取得該登入會員收藏的所有願望清單商品列表。

POST /api/wishlist/toggle

會員專屬。切換指定商品的收藏狀態（加入/移出願望清單）。參數：{"product_id": 1}

POST /api/products/{id}/subscribe

會員專屬。訂閱商品補貨與降價通知（當庫存從 0 變為大於 0，或者商品 base_price 降價時，系統將自動寫入 Email 隊列並發送 LINE Flex Message）。

POST /api/me/line-bind

會員專屬。連結會員之 LINE 官方帳號使用者識別碼，用於雙管道通知投遞。參數：{"line_user_id": "Uxxx"}

管理員後台 API 模組 (Admin Endpoints)

GET /api/admin/dashboard?period={7d|30d|1y}

取得管理員營收指標、近階段營收與訂單趨勢、熱銷 Top 5 商品與低庫存 (stock ≤ 5) 警示列表。

GET /api/admin/orders?page=1&status={status}&keyword={query}

分頁取得全站訂單列表，支援依訂單狀態篩選及關鍵字（訂單號、姓名、Email）搜尋。

PUT /api/admin/orders/{id}

更新訂單狀態及填寫物流資訊。若更新為 cancelled (已取消)，自動開啟 DB Transaction 還原 SKU 庫存與退還會員紅利點數。

GET /api/admin/coupons

取得全站折價券列表與使用統計。

POST /api/admin/coupons

建立新折價券（設定折扣類型、滿額門檻、有效期限與發行上限）。

PUT /api/admin/coupons/{id}/toggle

一鍵啟用或停用指定折價券。
