管理員後台 API 模組 (Admin Endpoints)

GET /api/admin/orders?page=1&status={status}&keyword={query}

分頁取得全站訂單列表，支援依訂單狀態篩選及關鍵字（訂單號、姓名、Email）搜尋。

GET /api/admin/orders/{id}

取得單一訂單詳細資料（包含商品細項、收件資訊、點數折抵、折價券與物流號碼）。

PUT /api/admin/orders/{id}

更新訂單狀態及填寫物流資訊。若更新為 cancelled (已取消)，自動開啟 DB Transaction 還原 SKU 庫存與退還會員紅利點數。

Request Body

{
  "status": "shipped",
  "shipping_carrier": "black_cat",
  "tracking_number": "BC-88991234"
}
GET /api/admin/coupons

取得全站折價券列表與使用統計。

POST /api/admin/coupons

建立新折價券（設定折扣類型、滿額門檻、有效期限與發行上限）。

PUT /api/admin/coupons/{id}/toggle

一鍵啟用或停用指定折價券。
